# 🌸 Thiệp Mời Điện Tử - Bản Giao Hưởng Nàng Thơ (Poetic Romance)

Dự án mẫu website thiệp mời cao cấp phong cách **"Nàng thơ" (Poetic / Romantic)** được xây dựng bằng **ReactJS, TypeScript, Tailwind CSS và Framer Motion**.

---

## ✨ Tính Năng Nổi Bật

* **🌸 Màn mở "Cánh Cửa Hoa" (Intro Door Opening):** Cánh cửa hoa đôi tách mở sang 2 bên khi chạm vào nút mở không gian, vượt qua cơ chế chặn autoplay của trình duyệt để tự động phát nhạc mượt mà.
* **🎵 Âm nhạc nền:** Tích hợp sẵn bài hát *"Công Tử Văn Thơ - MONO"* cùng trình phát đĩa hoa mini ở góc màn hình.
* **🦋 Hiệu ứng Bầy bướm & Cánh hoa rơi (Canvas 60FPS):** Đàn bướm bay ngợp trời kèm vệt bụi tiên lấp lánh khi chạm vào bông hoa đào (Mascot).
* **🎻 Nút Cây Đàn tương tác:** Chạm vào phím đàn để phát/dừng nhạc kèm nốt nhạc `🎵 🎶 🎼` bay bổng và pháo hoa cánh hoa.
* **📱 Album ảnh 3D CoverFlow:** Tối ưu hóa vuốt chạm cảm ứng trên điện thoại di động mượt mà.
* **💌 Sổ Lưu Bút & Xác Nhận Tham Dự (RSVP):** Khách mời ghi danh và gửi lời chúc trực tiếp theo thời gian thực.
* **🎁 Hộp Quà Mừng VietQR:** Quét mã QR chuyển khoản và sao chép số tài khoản tức thì với 1 cú click.
* **🔗 Cá Nhân Hóa Link Mời (V.I.P):** Công cụ tạo link mời riêng cho từng khách (`?guest=Tên_Khách&greeting=Lời_Mời`) hoặc tạo hàng loạt từ Excel.
* **📱 Tối ưu Mobile-First:** Tương thích hoàn hảo trên mọi kích thước màn hình từ điện thoại đến máy tính.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend:** React 19, TypeScript (TSX)
- **Styling:** Tailwind CSS, Custom Clip-paths & Rose Gold Gradients
- **Animations:** Framer Motion, HTML5 Canvas Simulation, Canvas Confetti
- **Icons:** Lucide React
- **Build Tool:** Vite

## 🚀 Hướng Dẫn Cài Đặt & Chạy Nội Bộ

### Cách 1: Chạy nhanh bằng file Batch (Windows)
Bấm đúp chuột vào file:
```text
CHAY_MAU_WED.bat
```
Trình duyệt sẽ tự động mở tại địa chỉ: `http://localhost:8888`

---

### Cách 2: Chạy bằng dòng lệnh Terminal
```bash
# 1. Cài đặt các gói thư viện
npm install

# 2. Khởi chạy dev server (cổng 8888)
npm run dev

# 3. Đóng gói bản chạy production
npm run build
```
